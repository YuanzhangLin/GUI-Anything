CODE TARGET

5 / 5 目标行新增命中

DetailFragment.deleteMergedNotes 的循环体与删除调用：1630、1631、1632、1633、1635 行，操作前覆盖指令为 0，操作后全部命中。

方法覆盖：9/9 行 · 35/35 条指令 · 3/4 分支。普通保存也会调用该方法，所以单看方法覆盖不足以判定成功。

PERSISTED RESULT

两条原记录 → 一条合并记录

数据库验证两条原笔记 ID 已删除，新笔记同时保留两段正文，无关记录未变。

含数据准备共 20 次 UI 操作，预算为 60 次。APK 哈希一致，JaCoCo 未报告 class 不匹配；每次采集重置探针后比较新增覆盖。

能力边界：由 Agent 阅读源码、观察实时 UI，并使用本地 ADB 脚本执行。此案例不是现有导航器的端到端自动化基准，也不代表成功率或全分支覆盖。仅发布整理后的说明，原始实验数据、截图、APK、数据库及执行脚本不上传。
