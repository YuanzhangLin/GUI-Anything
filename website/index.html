01 / 对应代码

保存合并结果后，删除原笔记

omniNotes/src/main/java/it/feio/android/omninotes/DetailFragment.java · 第 1627–1637 行

private void deleteMergedNotes (List<String> mergedNotesIds) {
  ArrayList<Note> notesToDelete = new ArrayList<>();
  if (mergedNotesIds != null) {
    for (String mergedNoteId : mergedNotesIds) {
      Note note = new Note();
      note.set_id(Long.valueOf(mergedNoteId));
      notesToDelete.add(note);
    }
    new NoteProcessorDelete(notesToDelete).process();
  }
}

02 / 代码分析 → TASK

为什么要“多选 → 合并 → 保存”？

ListFragment.merge() 发布 NotesMergeEvent(false)；事件处理器将选中笔记 ID 写入 merged_notes，然后打开合并编辑页。保存后的 onNoteSaved() 才会调用上面的删除方法。普通保存传入空列表引用，不会命中循环体。

Task
创建两条可区分的测试笔记，选中并合并，保存合并笔记，使两条原记录被删除。确认新笔记保留两段正文，并通过 JaCoCo 验证循环体和删除调用新增覆盖。只操作本次创建的测试笔记；预算 60 次 UI 操作、30 分钟。

以上为执行前冻结任务的中文整理，不是运行器自动生成的原始输出。
