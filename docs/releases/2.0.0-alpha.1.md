# GUI-Anything 2.0.0-alpha.1

This is an early preview of the skill-first Android-to-Map workflow. The map models user-visible screens and paths, with code locations as evidence.

## Included

- Fast static Map generation from an Android source tree, with standalone HTML review.
- A reusable `gui-anything` Skill, with Cursor and OpenCode discovery copies.
- Map review with path status, notes, JSON export, and runtime trace replay.
- Deterministic path planning and an experimental ADB observe–act–verify runner.
- A public demo and static website. The demo contains no decompiled project or conversation data.
- Optional platform UI, APK import through JADX, and Agent integration.

## Known limits

- The ADB runner passed mocked end-to-end tests but has not been validated against a connected device running the sample app. Treat its navigation results as experimental.
- Static analysis covers only some Fragment, menu, and transition patterns. Review ambiguous triggers against source evidence.
- OpenCode availability and its provider credentials depend on the local or container installation. Other agents can use the Skill and CLI directly.

## Verification before release

- Backend: `python -m unittest discover -s tests -q` (19 passed).
- Frontend: `npm run build` (passed).
- Website JavaScript: `node --check website/app.js` and `node --check website/viewer.js` (passed).

The stable `2.0.0` release should follow real-device navigation and deployment checks.
